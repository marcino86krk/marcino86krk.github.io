Instrukcja Wdrożenia w Sieci

Aplikacja jest w pełni samodzielnym plikiem HTML (Single File App) zawierającym HTML, style Tailwind CSS oraz logikę JavaScript. Możesz ją opublikować w kilka minut za darmo na dowolnym hostingu statycznym:

1. GitHub Pages (Najpopularniejsze)

  1. Zapisz kod jako plik index.html.
  2. Utwórz nowe repozytorium na GitHub i wrzuć tam plik.
  3. Wejdź w Settings -> Pages -> w sekcji Build and deployment wybierz gałąź main i folder / (root).
  4. Strona będzie dostępna pod wygenerowanym adresem GitHub.

2. Netlify / Vercel / Cloudflare Pages (Szybkie Przeciągnij i Upuść)

  1. Wejdź np. na Netlify Drop.
  2. Przeciągnij folder zawierający plik index.html (nazwany np. index.html) w wyznaczone miejsce na stronie.
  3. Netlify natychmiast wygeneruje działający link publiczny do Twojej aplikacji True Crime!
